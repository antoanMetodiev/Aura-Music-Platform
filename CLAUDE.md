# Aura Music Platform — работни правила за Claude Code

## Тестове — НЕ пиши никакви (действащо от 2026-09-13)

**Не пиши тестове от никакъв вид**, докато потребителят изрично не поиска това в конкретния момент:

- без unit тестове
- без integration тестове
- без Testcontainers / real database тестове
- без каквато и да е друга форма на автоматизирано тестване

Причина: писането на тестове (особено integration + Testcontainers) е изключително token-скъпо и потребителят изрично отказва да плаща тази цена, докато не поиска тестове конкретно.

**Не изтривай съществуващите тестове**, които вече са написани (напр. в `microservices/catalog-svc/src/test/`) — те си остават. Просто не добавяй нови, не разширявай съществуващите, и не пиши тестове "за да проверя дали работи" — вместо това, ако трябва да провериш нещо, пусни приложението директно (`bootRun`, `npm run dev` и т.н.) и провери ръчно/през curl, вместо да пишеш test клас.

Това правило важи за целия monorepo — front-end и всички microservices.
